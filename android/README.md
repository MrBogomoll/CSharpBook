# Android-приложение «Учебник C#»

Папка содержит Android-оболочку для того же учебника из соседнего `wwwroot`. В APK входят уроки, архивы проектов, редактор и обе среды выполнения. Приложение открывает содержимое во встроенном Android System WebView. Для сетевых сокетов локального сервера используется разрешение INTERNET. Сервер слушает только 127.0.0.1. Внешние ссылки открывает выбранный на телефоне браузер, а проекты ZIP сохраняются через системный выбор файла.

Для запуска примеров C# 15 на .NET 11 нужен Android System WebView версии 137 или новее. Версию компонента можно открыть в настройках приложений Android.

## Сборка на Windows

Нужны PowerShell, JDK, Python и команды curl.exe и tar.exe. Из корня исходного проекта выполни:

```powershell
pwsh -File ./android/Build-Apk.ps1 -WebRoot ./wwwroot -WorkDir ./build-android
```

Путь к JDK можно передать через `-JavaHome`, к итоговому APK — через `-OutputApk`. Первая сборка скачивает платформу и инструменты Android SDK 36 и NanoHTTPD. В последующих сборках используются локальные копии. Перед созданием пакета подготовь итоговые `course.json`, `sw.js` и каталоги `runtime` и `projects` в `wwwroot`.

Стабильная версия 0.2.0 использует versionCode 5. Первый стабильный выпуск 0.1.0 использовал versionCode 2. Для установки обновления поверх прежней версии нужен больший versionCode и тот же ключ подписи. Скрипт сверяет содержимое APK с исходниками и проверяет подпись и выравнивание файла.
