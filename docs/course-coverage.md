# Где найти темы справочника в Sharpwise

Сопоставлены 190 подпунктов в 27 разделах по присланному оглавлению для C# 13 и .NET 9. Порядок ниже соответствует этому изданию. В самом курсе главы выстроены по необходимым знаниям. Базовые программы выполняются на .NET 10, для материала по C# 15 используется .NET 11.

В приложении открой **Оглавление → Указатель тем** и введи термин. У каждого результата есть переход к главе.

| Формат | Что можно сделать |
| --- | --- |
| Практика | Выполнить тематический пример или упражнение в учебной консоли. |
| Разбор | Проследить поведение по коду и объяснению в главе. |
| На ПК | Выполнить опыт в терминале, в Visual Studio или в локальном проекте. |
| Справка | Прочитать назначение технологии и ограничения её применения. |
