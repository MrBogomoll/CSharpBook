# Облачная синхронизация

В приложениях для Android и Windows выбери в настройках Google Диск или Яндекс Диск. При первом входе Sharpwise прочитает данные с диска и объединит их с прогрессом на устройстве. Кнопка «Восстановить прогресс» повторяет загрузку. Кнопка «Синхронизировать сейчас» также отправляет изменения на диск.

У подключённого диска настрой частоту обмена на этом устройстве. По умолчанию включено «При изменениях». Для регулярных проверок включи «По таймеру». Можно выбрать 1, 5, 15, 30 или 60 минут либо указать «Свой интервал». Чтобы проверять диск каждые полтора часа, введи 1 в поле «Часы», 30 в поле «Минуты» и нажми «Сохранить интервал». Доступен диапазон от 1 минуты до 99 часов 59 минут. Пока ты вводишь время, действует прежний интервал.

Можно включить оба режима, оставить один или снять обе галочки для ручной синхронизации. Таймер работает, пока учебник открыт. Если интервал истёк в фоне или без интернета, проверка выполнится после возврата в приложение и восстановления связи.

При обновлении приложения поверх установленной версии сохраняются локальный прогресс и настройки подключения. Android-версии с 0.5.1 подписаны новым ключом. При переходе с версии со старой подписью сначала синхронизируй прогресс и проверь резервную копию. После переустановки подключи диск с этой копией и восстанови прогресс. [Инструкция по установке](../README.md#установка-и-первый-запуск)

## Google Диск

В Sharpwise открой «Настройки → Синхронизация → Подключить Google Диск». Если уже подключён другой сервис, сначала нажми «Сменить диск». Выбери один Google-аккаунт на телефоне и ПК. На Android подтверди доступ к данным Sharpwise. Приложение создаст файлы прогресса в своей закрытой папке Google Диска.

При первом подключении на Windows вставь полный **Client secret** клиента **Sharpwise Windows** или открой сохранённый при его создании JSON. После успешного входа Sharpwise сохранит ключ в зашифрованном хранилище текущего пользователя Windows. На этом ПК повторный вход и обновление приложения используют сохранённый ключ.

Если ключ не сохранился, в Google Cloud открой **Google Auth Platform → Clients → Sharpwise Windows → Client secrets → Add secret**. Скопируй новое значение в момент создания и сохрани в менеджере паролей. Внешним тестовым пользователям нужен доступ к проекту через список **Audience → Test users**.

Папки и пары файлов, подключённые в прежних версиях, продолжают работать после обновления. В браузерной версии можно скачать копию прогресса и восстановить её из файла.

### Регистрация Sharpwise для входа через Google

Эти действия один раз выполняет владелец приложения. После регистрации и выпуска обновления читатель нажимает **«Подключить Google Диск»** на телефоне и ПК и выбирает один и тот же аккаунт. Sharpwise сам создаёт файлы прогресса в закрытой папке приложения.

1. Открой [Google Cloud](https://console.cloud.google.com/). В переключателе проектов выбери **Sharpwise**. Если проекта ещё нет, нажми **New project**, введи `Sharpwise` и после создания выбери его.
2. В библиотеке **APIs & Services → Library** найди **Google Drive API** и нажми **Enable**. Перейди в **Google Auth Platform**. При первом запуске нажми **Get started**, введи название `Sharpwise` и свою почту для поддержки и уведомлений. Для личного аккаунта выбери аудиторию **External**.
3. Для проверки на своём телефоне открой **Audience → Test users → Add users** и добавь Google-аккаунт, с которым собираешься войти в Sharpwise. На странице **Data Access → Add or remove scopes** добавь доступ к данным самого приложения. Значение для поиска можно скопировать.

   ```text
   https://www.googleapis.com/auth/drive.appdata
   ```

4. Открой **Clients → Create client → Android**. Введи название `Sharpwise Android`. В поле **Package name** вставь имя пакета.

   ```text
   ru.csharpbook.reader.preview
   ```

   В поле **SHA-1 certificate fingerprint** вставь отпечаток и нажми **Create**. Для версий с 0.5.1 создай дополнительный Android-клиент с указанным ниже отпечатком. Сохрани предыдущий клиент, чтобы пользователи 0.5.0 могли синхронизировать данные до перехода.

   ```text
   F2:24:BD:C1:0C:92:B4:4C:29:E9:57:92:D4:DC:D6:DD:9C:F1:BE:58
   ```

5. В том же проекте выбери **Clients → Create client → Desktop app**, введи `Sharpwise Windows` и нажми **Create**. Для подготовки сборки скопируй публичный **Client ID** из карточки **Sharpwise Windows**. Его адрес заканчивается на `.apps.googleusercontent.com`. При создании сохрани также **Client secret** для первого входа на ПК.

После регистрации Android-клиента включи `googleAndroidConfigured` в параметрах сборки. Для Windows укажи публичный идентификатор в `googleDesktopClientId`. Когда приложение готово для других аккаунтов, настрой публикацию в разделе **Audience**.

[Управление ключами Google](https://support.google.com/cloud/answer/15549257) · [Создание клиентов Android и Desktop](https://developers.google.com/workspace/guides/create-credentials) · [Папка приложения в Google Drive](https://developers.google.com/workspace/drive/api/guides/appdata) · [Вход на Windows](https://developers.google.com/identity/protocols/oauth2/native-app)

## Яндекс Диск

В Sharpwise 0.3.3 обе платформы используют зарегистрированное приложение Яндекс ID из `cloud-sync.defaults.json`. Пользователь нажимает «Подключить Яндекс Диск» и разрешает доступ к папке Sharpwise. Сборки используют PKCE.

Для своего экземпляра зарегистрируй OAuth-приложение типа **«Для авторизации пользователей»**. В разделе «Веб-сервисы» укажи адреса возврата из таблицы, в доступах выбери «Доступ к папке приложения на Диске» (`cloud_api:disk.app_folder`). Укажи один публичный ClientID для обеих платформ.

| Платформа | Redirect URI |
| --- | --- |
| Windows | `http://127.0.0.1:53823/callback` |
| Android, стабильная и бета | `ru.csharpbook.reader.preview://oauth/yandex` |

[Регистрация приложения с адресами возврата](https://yandex.ru/dev/id/doc/ru/register-auth) · [Обмен кода с PKCE](https://yandex.ru/dev/id/doc/ru/codes/code-url)

## Параметры сборки

Обычная сборка использует публичные параметры Google и Яндекса из `cloud-sync.defaults.json`. Для собственной регистрации сохрани конфигурацию Windows в отдельном JSON-файле за пределами репозитория. В поле `yandexClientId` скопируй нужный публичный ClientID.

```json
{
  "googleDesktopClientId": "",
  "googleDesktopClientSecret": "",
  "yandexClientId": ""
}
```

При публикации Windows-приложения передай полный путь через `-p:CloudSyncConfig="C:\build\windows\cloud-sync.json"`. Для локальной проверки настройки также читаются из `%LOCALAPPDATA%\CSharpBook\cloud-sync.json` текущего пользователя Windows.

Для Android оба варианта сборки по умолчанию используют `cloud-sync.defaults.json`. Для другой регистрации скопируй `android/cloud-sync.example.json` в `android/cloud-sync.json` и заполни поля. Тестовая сборка принимает свой JSON через `./android/Build-Apk.ps1 -Preview -CloudConfig C:\build\preview\cloud-sync.json`. При обновлении APK используй прежний каталог подписи. Токены пользователь получает на своём устройстве при подключении диска.

## Проверка перед выпуском

Подключи один и тот же аккаунт на Windows и Android. Создай заметку на телефоне, дождись статуса синхронизации и проверь её на ПК. Измени один черновик на двух отключённых от сети устройствах, подключи их по очереди и выбери нужную версию в настройках. Повтори проверку со вторым сервисом. В режиме общей папки дождись также завершения передачи файлов облачным клиентом.
